# Contributing

Contributions should improve defensive security architecture, clarity, evidence, resilience, usability, or documentation.

## Good contributions

- Threat-model improvements
- Defensive controls
- Security testing
- Documentation
- Diagrams
- Reference implementations
- Accessibility and usability
- Standards mapping

## Avoid

Do not submit credentials, private keys, malware, destructive automation, unauthorized-access tooling, or instructions for bypassing real-world critical infrastructure protections.
