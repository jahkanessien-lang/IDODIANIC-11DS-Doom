# 11DS — 11-Dimensional Security

11DS is a defense-in-depth architecture for protecting an entire technology ecosystem.

## Mission

Design systems that remain controllable and recoverable when individual controls fail.

11DS uses a controlled-survivability model:

1. Prevent where practical.
2. Minimize attack surface.
3. Authenticate and authorize explicitly.
4. Segment systems and limit blast radius.
5. Detect abnormal behavior.
6. Contain safely.
7. Preserve trustworthy evidence.
8. Recover from a known-clean state.
9. Independently verify important controls.
10. Continuously improve.

## The 11 dimensions

1. People, Identity & Trust
2. Data & Cryptography
3. Devices & Platforms
4. Applications, Software & Supply Chain
5. Infrastructure, Cloud & Compute
6. Networks & Communications
7. Operations, Detection & Incident Response
8. Physical, Environmental & Cyber-Physical Security
9. AI, Agents, Quantum & Emerging Technology
10. Risk, Resilience & Continuity
11. Governance, Compliance & Independent Assurance

## Public/private boundary

This repository is intended for public architecture and documentation. Do not commit passwords, private keys, API tokens, production secrets, recovery credentials, internal addresses, sensitive infrastructure diagrams, or operational security details.

## Status

11DS is an architecture/research project. It is not a certification, guarantee, or claim that a system can never be compromised.
