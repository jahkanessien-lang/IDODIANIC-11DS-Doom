# GitHub Pages Deployment

This package is designed to work as a static GitHub Pages site.

## Steps

1. Create a GitHub repository, e.g. `11DS`.
2. Upload the contents of this package to the repository root.
3. Keep the repository **Public** if you want public discovery.
4. In GitHub: Settings → Pages.
5. Select **Deploy from a branch**.
6. Select the default branch and `/ (root)`.
7. Save.
8. GitHub will provide a Pages URL.
9. Optionally connect a custom domain in the Pages settings.
10. Add the published URL to Google Search Console and request indexing.

## Before publishing

Search the repository for secrets and sensitive operational data. The public package should contain architecture and documentation, not production credentials or private infrastructure information.
